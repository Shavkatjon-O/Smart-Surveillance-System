Smart Surveillance System is a video surveillance platform for IP cameras with its own video analytics. It shows every camera live in the browser, on a TV and on the phone, drives PTZ cameras and their settings over ONVIF, keeps the events the cameras report, and runs analytics on an NVIDIA GPU with DeepStream: people, vehicles and animals in zones and across lines, faces, tampering, counts, objects left behind, falls, number plates and a person's way across the cameras.

It runs today as a self-hosted installation on one computer in a site's own network. The platform API is multi-tenant: people sign up, belong to organisations, and see the sites their role and scope allow, so the same backend can later run centrally for many homes, stores, offices and warehouses.

## How the pieces fit

![Platform overview](/diagrams/platform-overview.png)

- go2rtc pulls each camera once and serves the original stream to the analytics engine and a browser-friendly H.264 stream to the console.
- The analytics engine reads its configuration from the API every 5 s and posts events back, so zone and rule changes apply without a restart.
- The console and the mobile app talk only to the API; the TV app talks to the cameras itself on the local Wi-Fi.
